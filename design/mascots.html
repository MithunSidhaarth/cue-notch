Cue pets

Each pet lives in the notch (top of each card, at its real ~28 px size) and is shown large below. Pick a moment to see every pet react to it. Accessories (headphones, notes, zzz, bubbles) are shared, so any pet can wear them.

All pets are drawn in code (SVG), use one accent colour, and fall back to a still pose with Reduce motion on. None copies an existing character.
